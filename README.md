# TaskFlow – A Simple Task Management System

TaskFlow is a small software project demonstrating key Software Engineering concepts:
requirements analysis, UML modeling, architecture design, phased development,
quality assurance and team-oriented planning.

This repository includes:
- UML diagrams (Use Case, Class, Sequence)
- Requirements specification
- Chosen process model (Scrum simulation)
- Architecture documentation
- Functional Flask application (CRUD tasks)
- Unit tests
- Sprint plan & backlog

## Features
- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete

## Software Engineering Concepts Demonstrated
- Requirements engineering
- UML modeling
- Scrum-based development planning
- Model-driven design
- Testing & quality assurance
- Version control workflows (Git)
